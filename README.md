Clicky for WordPress
====================

WordPress plugin for Clicky.com Analytics


Welcome to the Clicky for WordPress Github repository
-----------------------------------------------------

While the [Clicky for WordPress plugin](https://wordpress.org/plugins/clicky/) itself can be found on WordPress.org, here
you can browse the source of the project, find and discuss open issues and even
[contribute yourself](https://github.com/jdevalk/clicky/blob/develop/CONTRIBUTING.md).

This repository uses [the plugin grunt tasks](https://github.com/Yoast/plugin-grunt-tasks) originally written by Yoast.

Installation
------------

You can install Clicky in your WordPress site [from WordPress.org](https://wordpress.org/plugins/clicky/).
If you want to run the Git version though, you have two options:

* You can clone the GitHub repository: https://github.com/jdevalk/clicky.git
* Download it directly as a ZIP file: https://github.com/jdevalk/clicky/archive/develop.zip

This will download the latest development version of Clicky for WordPress. While this version is usually stable,
it is not recommended for use in a production environment.

Bugs
----
If you find an issue, [let us know here](https://github.com/jdevalk/clicky/issues/new)!

Support
-------
This is a developer's portal for Clicky for WordPress and should not be used for support. Please visit the
[support forums](https://wordpress.org/support/plugin/clicky).

Contributions
-------------
Anyone is welcome to contribute to Clicky for WordPress. Please
[read the guidelines](https://github.com/jdevalk/clicky/blob/develop/CONTRIBUTING.md) for contributing to this
repository.

There are various ways you can contribute:

* [Raise an issue](https://github.com/jdevalk/clicky/issues/new) on GitHub.
* Send us a Pull Request with your bug fixes and/or new features.
* [Translate Clicky for WordPress into different languages](https://translate.wordpress.org/projects/wp-plugins/clicky/).
* Provide feedback and [suggestions on enhancements](https://github.com/jdevalk/clicky/issues?direction=desc&labels=Enhancement&page=1&sort=created&state=open).
